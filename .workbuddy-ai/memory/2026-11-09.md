## Q73 — 前端 UI/UX 全面审查 + 重构方案（只诊断未改代码）

用户要求：按 TradingView/QuantConnect/Hyperliquid 风格重构控制台，7 个模块
（Dashboard / Strategy Lab / Backtesting / Trading Terminal / Automation / Risk /
Data Center），**先分析给方案，不要擅自改代码**。

产出：`docs/UI_UX_REFACTOR_PLAN.md`（397 行）。本文件只记结论与坑。

### 现状量化（都是实测，不是印象）

- `static/app.js` 4300 行 / 219KB / **140 个顶层函数**，无模块边界。
- `static/style.css` 618 行 / 69 类 / **12 种字号**（10–21）/ **9 种 margin-top**（2,5,7,8,9,10,11,12,14）。
- `app.js` 里 **200 处** `style="..."` 内联逃逸（`margin-top:14px` 14 次、`font-size:11.5px` 25 次）。
- 40 个 API 端点（server 12 + live_api 28）。3 个 tab，hash 路由。
- 响应式**只有 1 个断点**（1080px）。`0` 处骨架屏、`33` 处纯文本空态、`confirm()`×3、`alert()`×5。

### 三个「后端有、前端没接」的功能缺口（最值钱的部分）

1. **回测取消**：`POST /api/runs/<id>/cancel` 存在（`server.py:946`，`_cancel` 在 1358），
   **前端 0 处调用**（`grep cancel` 只命中状态文案 `'已取消'`）。
2. **撤单**：`okx_private.py` 有 `cancel_order`(692) / `cancel_all`(702) /
   `orders_pending`(720)，**全仓零调用点**（grep 排除定义后为空）⇒ 死代码，
   挂单既看不到也撤不掉。
3. **暂停 ≠ 停止 未区分**：只有 `/api/live/auto/start|stop`，没有「本周期暂停」。

### 架构坑（改造前必须知道）

- 🔴 `app.js` 被 **8 个 harness**（`scripts/smoke_ui.js`、`smoke_live.js`、
  `check_dom_refs.js`、`check_js.js`、`verify_auto_panel/input_persist/navhist/refresh_and_mode.js`）
  + **2 个守卫测试**（`test_console_api_contract.py` 用正则抓 `deleteRun()` 与
  `fetch('/api/runs/'...)`；`test_universe_drift.py` 用 node vm 真渲染）直接读取。
  ⇒ **拆 app.js 会让它们静默失效**。方案里把拆分放最后（P2-5），先改 harness 再搬。
- 🔴 `/static/` 用 `os.path.basename(p)`（`server.py:830`）**扁平化** ⇒
  新 JS 必须平铺在 `static/` 下，建子目录会 404。`/static/` 前缀是公开的（免登录）。
- 登录页渲染进 `#content`（`authLogin` → `$('#content').innerHTML`）⇒
  **未登录时顶栏（含「运行回测」）与空侧栏仍然可见**，表单被挤在右侧。
- `.main { grid-template-columns: 412px 1fr }` 且 `renderSide()` 只在 boot 调一次 ⇒
  **回测参数侧栏常驻所有页面**，在交易台页占 32% 宽度且内容无关。
- canvas 图表只有 `window.resize` 监听、**无 ResizeObserver** ⇒ 无窗口尺寸变化的布局
  变化（tab 切换、异步内容撑开）不重绘；`.ui_preview/ui_dark.png` 里净值曲线空白疑此因。

### 方案骨架

P0（纯前端，后端零改动）：tokens + `ui.js` 组件 + 全局壳（64px 图标导航 + 登录页独立）
+ 三态 + 回测取消接线 + 枚举翻译 + ResizeObserver。
P1（**追加**端点，不改契约）：Dashboard、任务中心 `/api/tasks`、通知中心 `/api/events`、
危险操作五件事（`/api/live/pause|cancel-orders|emergency`）、挂单 `/api/live/pending`。
P2（结构性）：Strategy Lab 版本、横向对比表、Data Center、行情/K线、拆 app.js。

不变量：涨红跌绿、`fmt.dol` 两位小数、指标只来自 `/api/spec`、实盘确认短语、
`preserveUi()`、`/api/` 错误必须是 JSON。

### 这一轮真踩到的坑

1. 🔴 **竖排骨架条塌成 0 高**（只有真渲染才发现）。`.skel` 是 `flex-direction:
   column` 且高度 auto，`.skbar` 的 `flex: 1` = `flex-basis: 0` ⇒ 每根条被压成
   0px，界面上只剩一句「正在读取」，和没加骨架一样。**表格形态因为有固定高的
   `.skrow` 才没露出来** ⇒ 只看表格那一屏是发现不了的。修法
   `.skel > .skbar { flex: 0 0 auto; width: 100% }`。实测 18 根条全部 10px。
2. 🔴 **改文案/改代码形态会让 harness 与守卫静默失效**。`smoke_live.js` 用
   `includes('正在读取账户')` 判断「切模式期间有没有显示旧模式净值」，
   `verify_auto_panel.js` 用 `!includes('正在读取')` 判断「加载完了没有」，
   `smoke_live.js` 还断言 `includes('点「生成下单计划」开始')` /
   `includes('尚未生成计划')`。⇒ 换外壳可以，**文案一个字都不能改**（骨架保留
   一句说明、空态把原文案放进 title）。
   守卫也吃字面形态：`test_universe_upgrade.py::test_frontend_binding_wired` 用
   `if \(!window\.confirm\([\s\S]*?\)\) return;` 钉「确认结果必须门控 liveSubmit」，
   把 `window.confirm` 换成 `ui.modal` 它当场红。**改完要同步改写断言，强度不许降**
   （新断言：取到结果 + `if (!ok) return;` + 门控在调用之前 + 块内只有一次调用），
   并重跑变异（去掉门控/门控后置/加旁路/结果不接，4 个全部被抓）。
   ⚠️ 变异脚本 `replace(old,new,1)` 可能命中**别处同名片段**（`const ok = await
   ui.modal(` 在 runNow 里也有）⇒ 变异锚点必须先断言 `count(old)==1`。
3. 🔴 **`git commit -m "...\`code\`..."` 在 zsh 会被反引号当命令替换** ⇒
   `command not found: .skel` + 整条命令 parse error。含反引号的提交信息必须写进
   文件再 `git commit -F`。（与「`echo ===` 等号展开」同族。）
4. `check_js.js` 的浏览器全局白名单缺 `ResizeObserver` ⇒ 把浏览器全局误报成
   「调用未定义」。已补 `ResizeObserver/IntersectionObserver/MutationObserver/
   matchMedia`。
5. `test_deploy_script.py::test_downcast_does_not_change_results` 取
   `sorted(...)[:40]` 当样本，宇宙涨到 258 只后 `BTC-USDT-SWAP` 排第 43 ⇒
   基准列不在 panel 里、`engine.py:211` 直接 ValueError。补样本前提，断言不动。
6. pytest 必须 `TMPDIR="$(mktemp -d)"`，否则 `tmpdir` fixture 在沙箱里
   `mkdir` 被拒（20 个 error，看起来像大面积坏掉）。
